## 🚀 Getting Started

**Requirements:** Node.js ≥ 22.5, a WhatsApp account.

```bash
npm install
mv example.config.json config.json
nano config.json
npm start
```

Enter the pairing code into WhatsApp (Linked Devices → Link with phone number). That's it.
